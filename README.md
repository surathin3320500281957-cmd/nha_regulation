# ทะเบียนข้อบังคับและคู่มือบริหารชุมชน — การเคหะแห่งชาติ

Dashboard เดียวสำหรับค้นหาและสรุป **ขอบเขต / อำนาจ / หน้าที่** ของทั้งข้อบังคับ/ระเบียบและคู่มือปฏิบัติงานของ กคช. โดยไม่ต้องเปิดอ่าน PDF ทีละไฟล์

**Live URL:** `https://<username>.github.io/<repo-name>/`

ถ้าผู้ใช้พาคุณมาที่โปรเจกต์นี้ (อัปโหลดไฟล์นี้หรือลิงก์ repo) นี่คือสิ่งที่ต้องรู้ก่อนช่วยงานต่อ:

1. **โครงการนี้มี 2 ชุดข้อมูลคนละธรรมชาติกัน** — อย่าปนกัน:
   - `data.json` = **ข้อบังคับ/ระเบียบ** (กฎเกณฑ์ กำหนดอำนาจ) — 41 รายการ ครบ 100%
   - `manual.json` = **คู่มือปฏิบัติงาน** (ขั้นตอนทำงานจริง) จากไฟล์ต้นฉบับ "คู่มือการปฏิบัติงานสายงานบริหารชุมชน" 612 หน้า — 61 หัวข้อ ครบ 100% (แต่ยังมีบางหัวข้อที่ยังไม่มีตารางอำนาจแบบมีโครงสร้าง — ดูหัวข้อ "สถานะปัจจุบัน" ด้านล่าง)
2. **`index.html` มี 2 tab** สลับกันโดยใช้ id `viewBrowse` (ระเบียบ) และ `viewManual` (คู่มือ) — เขียนด้วย vanilla JS ล้วน ไม่มี framework ไม่มี build step
3. **ทุกอย่างเป็น static site บน GitHub Pages** — ไม่มี backend, ไม่มี database, ไม่มี AI ทำงานอยู่เบื้องหลังหน้าเว็บ (ค้นหาเป็น string matching ล้วนๆ)
4. **ถ้าผู้ใช้ขอให้เพิ่มระเบียบ/หัวข้อคู่มือใหม่** → อ่าน PDF ที่เขาอัปโหลด (หรือดึงจาก Google Drive โฟลเดอร์ "ระเบียบ" ถ้าเข้าถึงได้) แล้วเพิ่มเป็น object ใหม่ใน `items[]` ของไฟล์ JSON ที่เกี่ยวข้อง ตาม schema ด้านล่าง — **ไม่ต้องแก้ `index.html`** เว้นแต่จะเพิ่มฟีเจอร์ใหม่จริงๆ

## Schema: `manual.json` (คู่มือบริหารชุมชน)

```json
{
  "meta": {
    "title": "คู่มือการปฏิบัติงานสายงานบริหารชุมชน (ฉบับปรับปรุงปี 2566)",
    "source_url": "https://drive.google.com/file/d/.../view",
    "total_pages": 612,
    "issued_by": "...", "order_ref": "คำสั่ง กคช. ที่ จ.245/2565", "note": "..."
  },
  "items": [
    {
      "id": "m_h5_s10",                   // m_h{หมวด}_s{ส่วนที่} หรือ m_appendix_{เลข} สำหรับภาคผนวก
      "chapter_no": 5,                    // 1-7 = หมวดปกติ, 99 = ภาคผนวก
      "chapter_title": "ด้านการจัดการทรัพย์สิน",
      "section_no": "10",
      "title": "การจัดประโยชน์ในชุมชน",
      "page": 214,                        // เลขหน้า "พิมพ์" ในเล่ม (ไม่ใช่เลขหน้า PDF ดิบ — ดูหมายเหตุด้านล่าง)
      "sub": ["หัวข้อย่อย 1", "..."],      // ใช้เมื่อไม่มี content.steps (fallback)
      "related_regulation": ["reg_094"],  // เชื่อมไปยัง data.json — คลิกในหน้าเว็บจะสลับ tab ไปเปิดฉบับนั้นให้อัตโนมัติ
      "note": "หมายเหตุจากตอนทำ index (บางรายการ)",
      "content": {
        "overview": "ภาพรวมของหัวข้อนี้",
        "steps": [ { "title": "หัวข้อย่อย", "detail": "รายละเอียด/ขั้นตอน" } ],
        "note_extra": "หมายเหตุเพิ่มเติม (ถ้ามี — เช่น จุดที่ยังอ่านไม่ครบ)",
        "data_asof": "บอกว่าเนื้อหานี้ยืนยันด้วยภาพจริงแล้วหรือยัง"
      },
      "authority": [                       // ⚠️ มีเฉพาะ 20/61 หัวข้อ — ดูหัวข้อสถานะด้านล่าง
        { "holder": "ผู้ว่าการ", "category": "อนุมัติสัญญาเช่า", "limit": "ไม่เกิน 200 ล้านบาท", "note": "" }
      ]
    }
  ]
}
```

### ⚠️ สำคัญมาก — เรื่องเลขหน้า PDF ของคู่มือ (612 หน้า)

**เลขหน้า "พิมพ์" ในเล่ม ≠ เลขหน้า PDF จริง** เพราะมีหน้าปก/สารบัญคั่นอยู่ก่อน — สูตรแปลงที่ยืนยันแล้ว (คงที่ตลอดทั้งเล่ม):

```
PDF_page = printed_page + 11
```

ตัวอย่าง: field `page: 354` (หน้าพิมพ์) → ต้องใช้ `pdftoppm -f 365 -l 375` (PDF จริง) ถึงจะได้หน้าที่ถูกต้อง — **เคยพลาดจุดนี้มาแล้วครั้งหนึ่งในการอ่านหมวด 6.5** ถ้าจะกลับไปอ่านหน้าเพิ่มเติม ต้องบวก 11 เสมอ

### งานที่ค้าง/ต่อยอดได้ในอนาคต (ถ้าผู้ใช้ถามถึง)

1. **ระเบียบใหม่ที่พบซ่อนอยู่ในคู่มือ แต่ยังไม่อยู่ใน `data.json`** (พบระหว่างอ่านคู่มือ ยังไม่ได้แยกไปทำเป็น record เต็มในทะเบียนหลัก):
   - ระเบียบว่าด้วยการให้เช่า ให้เช่าซื้อ หรือซื้อ อาคาร ที่ดินฯ พ.ศ.2543 (+ฉบับที่ 2 พ.ศ.2562) — ภาคผนวก 13-14
   - ระเบียบว่าด้วยการให้เช่าโครงการเคหะชุมชนดินแดงฯ พ.ศ.2563 (+ฉบับที่ 2 พ.ศ.2565) — ภาคผนวก 15-16
   - ระเบียบว่าด้วยการจัดประโยชน์ทรัพย์สิน 4 ฉบับย่อย (เช่า/กิจกรรมชุมชน/สาธารณูปโภค/ผู้ประกอบการรายย่อย) พ.ศ.2563 — หมวด 5 ส่วนที่ 10.2-10.5
   - ระเบียบการจัดเก็บเงินและการนำส่งเงิน ฉบับที่ 2 พ.ศ.2563 — ภาคผนวก 17-18
2. **คำสั่งมอบอำนาจปี 2565 (ภาคผนวก 7-12) อาจล้าสมัย** — คู่มือ (ปรับปรุงปี 2566) ยังอ้างอิงคำสั่งชุดปี 2565 แต่ข้อบังคับหลัก `reg_delegation` ในทะเบียนเป็นฉบับปี **2568** (ออกทีหลัง 2 ปี) — ควรตรวจสอบว่าคำสั่งปี 2565 ยังมีผลบังคับใช้คู่ขนานหรือถูกยกเลิกไปแล้ว
3. **`authority[]` ยังไม่ครบทุกหัวข้อ** ที่มีข้อมูลอำนาจ (ดูตารางสถานะด้านบน) — ทำเพิ่มได้เรื่อยๆ ตาม schema ด้านบน แล้วตาราง "⚖️ ตารางอำนาจอนุมัติรวม" ในหน้าเว็บจะอัปเดตให้อัตโนมัติ (ไม่ต้องแก้โค้ด)

## ฟีเจอร์ในหน้าเว็บ (สรุปสั้นๆ)

- **Tab ระเบียบ**: ค้นหา + กรองหมวดหมู่ + คลิก tag ค้นต่อ + filter pill ล้างทีละตัว/ทั้งหมด
- **Tab คู่มือ**: เหมือนกัน + badge ⚖️(มีตารางอำนาจ) 🔗(เชื่อมโยงระเบียบ) 📌(มีหมายเหตุ) บนการ์ด + คลิก stat card กรองเฉพาะกลุ่ม + ปุ่ม **"⚖️ ตารางอำนาจอนุมัติรวม"** รวมทุก `authority[]` มาแสดงตารางเดียว เรียงจากตำแหน่งต่ำ→สูง พร้อม **export Excel (.xlsx)** และ **export PDF** (ผ่าน `window.print()`)
- คลิกปุ่มเชื่อมโยง (🔗) ในหัวข้อคู่มือ → สลับ tab ไปเปิดฉบับข้อบังคับที่เกี่ยวข้องให้อัตโนมัติ

## เทคนิคที่ใช้ตอนอ่าน PDF สแกน/ภาพ (ถ้าต้องอ่านเพิ่มในอนาคต)

หลายไฟล์เป็น PDF สแกนหรือมีเนื้อหาฝังเป็นรูปภาพในไฟล์ Word ที่แปลงเป็น PDF (`pdftotext` อ่านไม่ออกแม้จะเป็นไฟล์ digital) — วิธีที่ได้ผล:

```bash
pdftoppm -jpeg -r 150 -f <หน้าเริ่ม> -l <หน้าจบ> input.pdf output_prefix
tesseract output_prefix-XXX.jpg - -l tha
```

**บทเรียนสำคัญ:** อย่าเชื่อว่า `pdftotext` คืนค่าว่างแปลว่า "ไม่มีเนื้อหา" — ลอง OCR ด้วย tesseract ก่อนสรุปว่าหน้านั้นไม่มีข้อความเสมอ (เจอเนื้อหาจริงหลายจุดที่เคยสรุปผิดว่า "เป็นภาพล้วน" ตอนอ่านคู่มือ 612 หน้า)
